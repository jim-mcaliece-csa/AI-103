## Completion standard

Before checking off a module, aim to complete all four steps:

- [ ] Review the learning material
- [ ] Complete the hands-on exercise or lab
- [ ] Record useful notes, commands, and lessons learned
- [ ] Complete the knowledge check and review missed answers

Confidence scale: **1** = needs substantial review, **3** = can explain the main ideas, **5** = can implement and troubleshoot without help.
